# Trabajos-para-CV
Este repositorio muestra varios trabajos llevados a cabo durante los primeros semestres de la carrera de ISI que pueden comprobar mi mejora en la creación de proyectos.
A través del contenido mostrado en este repositorio se detallarán en qué me especialicé durante mi trabajo en cada actividad.

Trabajo 1:
En este trabajo se creó en equipos una base de datos que pudiera mantener un hospital. Dicho trabajo ejecuta las operaciobes CRUD y tiene un diseño para el front end. Aprendimos a organizar el trabajo entre los participantes del proyecto, escribir código para operaciones CRUD y diseño, investigar sobre versiones de java para correr el programa y conectar varios códigos para construir un solo programa.
